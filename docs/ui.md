# 画面仕様

仕様 §8 の SC-01〜SC-08 をルートと部品に対応付ける。モバイルファースト（幅 375px で崩れない）。UIライブラリは使わない。

## ルート

| ルート | 画面 | 仕様 |
| --- | --- | --- |
| `/login` | Login | Googleでログイン。money-lens の Login と同じ状態遷移 |
| `/` | RecipeList | SC-01 |
| `/recipes/new` | RecipeEdit（新規） | SC-03 |
| `/recipes/:id` | RecipeDetail | SC-02 |
| `/recipes/:id/edit` | RecipeEdit（編集） | SC-03 |
| `/recipes/:id/cook` | CookMode | SC-06 |
| `/recipes/:id/arrange` | ArrangeInput | SC-04 |
| `/recipes/:id/arrange/result` | ArrangeResult | SC-05 |
| `/recipes/:id/arrange/cook` | CookMode（一時アレンジ） | SC-06。sessionStorage の結果を表示 |
| `/techniques` | TechniqueList | SC-08 |
| `/techniques/new`, `/techniques/:id/edit` | TechniqueEdit | SC-08 |

`/login` 以外はすべて `RequireAuth` 配下。

## 共通レイアウト

- 上部ヘッダー: アプリ名「recipe-buddy」（`/` へのリンク）、右にユーザー名とログアウト。
- 料理モードではヘッダーを出さず、終了ボタンのみ。
- 主要ボタンは高さ 44px 以上、ラベル付き。
- 破壊的操作（削除）は `window.confirm` でよい（MVP）。

## SC-01 レシピ一覧（`/`）

- 検索入力（レシピ名の部分一致、即時フィルタ）
- カテゴリ選択（登録済みカテゴリから生成した `<select>`、「すべて」含む）
- タグ絞り込み（登録済みタグをチップ表示、複数選択 AND）
- 一覧: タイトル、カテゴリ、タグ、`親` / `子（元: 親タイトル）` の識別バッジ。`ai_arranged` は「AIアレンジ」バッジ
- 「新規登録」ボタン、「共通テクニック」リンク
- 空のときは案内文

## SC-02 レシピ詳細（`/recipes/:id`）

- タイトル、概要、人数、調理時間、カテゴリ、タグ
- 材料一覧（`名前：分量単位（補足）`）
- 番号付き手順。`StepText` 部品で `[[id|語句]]` をリンク風ボタンに描画
- 親レシピへのリンク（子のとき）、子レシピ一覧（親のとき）
- `ai_arranged` のとき「AIが生成したアレンジです」表示と `arrangementRequest`
- 操作: 料理モード / アレンジする / 編集 / 削除
- 削除時: 子がいれば「子レシピ N 件は親なしのレシピとして残ります」を確認文に含める

## SC-03 レシピ登録・編集

- 基本情報: タイトル（必須）、概要、人数、調理時間、カテゴリ、タグ（カンマ区切り）
- 材料: 行の追加・削除・上下移動。各行は 名前（必須）／分量／単位／補足
- 手順: 行の追加・削除・上下移動。各行はテキストエリア
- 手順のテクニック紐づけ: テキストエリアで語句を選択 → 「テクニックを紐づけ」→ テクニック選択ダイアログ → 選択範囲を `[[id|語句]]` に置換。選択が空なら「語句を選択してください」
- 保存 / キャンセル。必須不足はフィールド近くにエラー表示し保存しない
- 保存失敗時は入力を保持しエラー表示

## SC-04 アレンジ入力（`/recipes/:id/arrange`）

- 対象レシピ名と材料・手順の簡易表示（折りたたみ）
- 自由記述テキストエリア（プレースホルダに入力例）
- 「生成する」ボタン。生成中は無効化し「生成中…」表示（二重送信防止）
- キャンセルで詳細へ戻る
- 失敗時: エラー文と再試行ボタン。入力は保持

## SC-05 アレンジ結果（`/recipes/:id/arrange/result`）

- 元レシピ名、「AIが生成した内容です」表示
- 主な変更点（箇条書き）、安全上の注意、確認事項（あれば強調）
- 変更後の材料・手順（SC-02 と同じ部品で描画）
- 新規テクニック候補（あれば表示のみ。登録機能は付けない）
- 操作: 今回だけ料理する（→ `/recipes/:id/arrange/cook`）／ 子レシピとして保存（名前を確認するダイアログ → 保存 → 子の詳細へ）／ 要求を修正して再生成（→ SC-04、入力保持）／ キャンセル
- sessionStorage に結果がなければ SC-04 へリダイレクト

## SC-06 料理モード

- 大きめの文字（手順は 1.25rem 以上、行間 1.8）、余白広め
- レシピ名、材料一覧、番号付き手順（テクニックリンク有効）
- 画面上部に消灯抑止の状態: 「画面消灯を抑止中」「この端末では抑止できません」「抑止が解除されました（タップで再取得）」
- 「料理モードを終了」ボタン（画面下部固定）。終了で Wake Lock を解放し、元の詳細（または結果画面）へ戻る
- 編集・削除・アレンジ導線は出さない

## SC-07 共通テクニックモーダル（`TechniqueModal` 部品）

- `<dialog>` を使う。名称、説明、番号付き手順、注意点、閉じるボタン
- 開くときに `showModal()`、閉じたら開いた元のボタンにフォーカスを戻す
- 背景クリック / Esc で閉じる。閉じてもページのスクロール位置を変えない（body の `overflow` を触らない、または位置を保存して戻す）

## SC-08 共通テクニック管理（`/techniques`）

- 検索（名称部分一致）、一覧（名称、要約、参照レシピ数）
- 新規登録 / 編集 / 削除。削除確認に「参照中レシピ N 件（本文の語句はそのまま残ります）」を含める
- 編集画面: 名称（必須）、要約、手順（行の追加・削除・上下移動、1件以上必須）、注意点
