# 豚肉・じゃがいも・ピーマン・きのこのガーリックバター炒め

## 材料（2人分）

- 冷凍豚肉：200〜250g
- じゃがいも：2個
- ピーマン：2〜3個
- しめじ・舞茸などのきのこ：合計1パック程度
- にんにくチューブ：2〜3cm
- バター：10g
- 醤油：小さじ1〜2
- 塩：少々
- こしょう：少々
- 炒め油：少量

## 作り方

### 1. 冷凍豚肉を半解凍する

1. 冷凍豚肉を耐熱皿に出す。
2. 電子レンジ200Wで1分30秒〜2分加熱する。
3. 一度取り出し、剥がせる肉から1枚ずつ剥がす。
4. 中心がまだカチカチの場合は、30秒ずつ追加加熱する。

> 完全解凍する必要はない。1枚ずつある程度ほぐせる状態になればOK。

### 2. じゃがいもをレンジ加熱する

1. じゃがいもを5〜8mm程度の薄めの一口大に切る。
2. 耐熱容器に入れて軽くラップする。
3. 600Wで4〜5分加熱する。

> 少し硬さが残る程度でOK。フライパンで仕上げる。

### 3. 野菜を準備する

- ピーマン：細切り
- しめじ・舞茸：食べやすくほぐす

### 4. 豚肉を先に炒める

1. フライパンに油を少量入れ、中火〜やや強めの中火にする。
2. 半解凍した豚肉を入れ、菜箸で剥がしながら炒める。
3. 冷凍肉から出る水分を飛ばしながら、肉の色がほぼ変わるまで炒める。
4. 塩・こしょうを軽く振る。

> 冷凍肉は水分が出やすいので、野菜を最初から入れないのがポイント。

### 5. 野菜を加える

1. じゃがいもを加える。
2. きのこを加える。
3. ピーマンを加える。
4. 全体を2〜3分炒める。

### 6. 味付けする

1. にんにくチューブ2〜3cmを加える。
2. バター10gを加えて全体に絡める。
3. 醤油小さじ1を鍋肌から回し入れる。
4. 味見し、足りなければ醤油をさらに小さじ1追加する。
5. 豚肉に赤い部分が残っていないことを確認して完成。

# 豆腐・卵・わかめの味噌汁

## 材料（2人分）

- 水：400〜450ml
- だし：適量
- 豆腐：1/2丁
- 卵：1個
- 乾燥わかめ：ひとつまみ
- 味噌：大さじ2前後

## 作り方

1. 鍋に水とだしを入れて火にかける。
2. 豆腐をさいの目に切って加える。
3. 沸いたら弱火にし、2〜3分温める。
4. 乾燥わかめを加える。
5. 火を弱めるか一度止め、味噌を溶く。
6. 再び弱火にする。
7. 卵を溶き、細く回し入れる。
8. 10〜20秒触らず待つ。
9. 卵が固まり始めたら、そっと混ぜる。
10. 沸騰する前に火を止めて完成。

> 卵を入れた直後に混ぜないと、ふんわり仕上がりやすい。

# 水菜・ミニトマトのサラダ

## 材料（2人分）

- 水菜：1/2袋程度
- ミニトマト：6〜8個
- 好みのドレッシング：適量

## 作り方

1. 水菜を4〜5cm幅に切る。
2. ミニトマトを半分に切る。
3. 器に盛り付ける。
4. 食べる直前にドレッシングをかける。

## おすすめドレッシング

メインがガーリックバター味なので、以下のようなさっぱり系が合わせやすい。

- 青じそドレッシング
- 和風ドレッシング
- ポン酢系ドレッシング

# 同時調理の順番

1. 冷凍豚肉を200Wで半解凍する。
2. その間にじゃがいもを切り、600Wでレンジ加熱する。
3. 味噌汁を作り始め、豆腐まで入れておく。
4. 水菜とミニトマトを切り、サラダを準備する。
5. 豚肉を炒める。
6. じゃがいも・きのこ・ピーマンを加え、メインを完成させる。
7. 最後に味噌汁へ味噌と卵を加えて仕上げる。

## 調理メモ

- 冷凍豚肉は完全解凍しなくてもよい。
- 豚肉から出る水分を先に飛ばしてから野菜を入れると、べちゃっとしにくい。
- じゃがいもは事前にレンジ加熱しておくことで大幅に時短できる。
- 味噌汁は卵を入れてから10〜20秒触らず待つ。
- メインは甘辛味ではなく、にんにく・バター・醤油で香ばしく仕上げる。
